# Payoo Mobile - Premium Financial Interface

Payoo is a modern, mobile-first financial web application redesigned with a premium **Glassmorphism** aesthetic. This project transforms a basic functional interface into a high-end, interactive user experience using modern web technologies.

## ✨ Features

- **Premium UI/UX**: Implements a "Glassmorphism" design system with backdrop blur, vibrant gradients, and sleek typography.
- **Mobile-First Experience**: Optimized for mobile devices with a fixed bottom navigation bar and touch-friendly components.
- **Dynamic Dashboard**: Features a premium balance card with indigo-purple gradients and smooth micro-animations.
- **Unified Transactions**: Integrated modules for:
  - Add Money (Bank integration)
  - Cash Out (Agent withdrawal)
  - Transfer Money (P2P)
  - Get Bonus (Coupon system)
  - Pay Bills (Utility payments)
- **Interactive History**: Visual transaction logs with type-specific indicators and real-time updates.
- **Smooth Transitions**: Custom CSS animations for seamless section switching and interactive feedback.

## 🚀 Tech Stack

- **HTML5**: Semantic structure.
- **Tailwind CSS**: Modern utility-first styling.
- **DaisyUI**: Premium component library.
- **FontAwesome**: High-quality vector icons.
- **Vanilla JavaScript**: Lightweight and fast interaction logic.
- **Google Fonts**: "Poppins" typography for a premium, modern feel.
